# 塑料航线 · Plastic Airlines

在线多人联机趣味飞行棋：深蓝背景、四色棋盘、四个座位、候场和观战。支持经典模式与趣味大乱斗模式（机长技能、战术道具、结盟背叛、随机特殊格）。浏览器即可游玩，支持电脑与手机。

## 运行

需要 Node.js 20 或以上，无需安装第三方依赖。

```sh
npm start
```

打开 `http://localhost:8080`。创建房间后复制邀请链接，其他玩家通过链接或房间号加入。房主选择 2、3 或 4 人；入座人数满足人数设置后开始。

```sh
npm test
```

通过 `PORT` 和 `HOST` 环境变量设置监听地址，默认 `0.0.0.0:8080`。

## 本站规则

- 默认使用经典模式。房主可在开局前的等待大厅切换经典／趣味模式；趣味模式可分别开关加速、陷阱、安全岛、幸运格、冰冻格、撞飞台词动画、结盟与道具。前六项默认开启，结盟和道具默认关闭，可自由组合。所有玩家同步使用所选规则，开局后模式与开关锁定；经典模式不启用这些玩法。
- 每人四架飞机，掷出 2、4、6 点可选择从机场出门到本色停机坪，或移动已出门飞机；下次掷骰从停机坪进入同角相邻的公共三角格，该三角格计第一步。停机坪仅供所属颜色使用，不能被其他颜色进入或撞击；只有六点可再掷一次，2、4 点出门后换人。
- 中途换人或换设备时，原操作者打开“角色代码”并交给接替者；房主也可在“房间管理”查看并复制所有入座玩家的接管码。接替者以观战身份加入同一房间，打开“接管角色”输入该代码。飞机、回合、统计、已记录名次和剩余操作时间保留，原操作者转为观战；接管后会生成新代码，旧代码立即失效。已完成的角色不再接受接管。普通玩家仅能查看自己的代码，观战成员没有接管码。
- 对局开始前，房主可在“房间管理”确认移出其他玩家或观战成员，包括离线成员；被移出者的连接和旧凭证立即失效，需重新加入。对局中不能踢人，房主不能踢出自己。
- 掷出六点完成移动后可继续掷骰，不限制连续六点次数；完成比赛的玩家仍退出轮转，不再额外掷骰。
- 落到同色主环格跳四格；落到同色飞行标记格飞十二格。飞行落点不继续跳跃，同色跳跃与飞行奖励都限制在主环内。
- 普通移动、跳跃和飞行的落点可撞回敌机；飞越途中不撞机。同色可叠放。
- 公共外环上，同色两架或以上飞机叠放形成敌方“墙”，自己的墙不阻挡自己。骰子移动先检查前方最近的敌墙：点数不到墙时正常移动；刚好到墙时自爆破墙，移动飞机和墙上敌机全部回机场；超过墙时先走到墙前一格，再从那里后退“点数减去到墙距离”的格数。后退不低于本方外环起点，遇另一敌墙停在其前，只反弹一次；反弹不触发同色跳跃或特殊格。停机坪和归航道不形成公共外环墙。
- 同色跳跃和飞行保留飞越途中不撞机的规则，但奖励落点的敌墙仍优先结算为自爆破墙；墙落点为特殊格时也先破墙，特殊效果不触发。
- 趣味模式在公共主环四个象限各设置一个加速格、陷阱格、安全岛和幸运格，按房间开关生效：加速格前进 2 格，陷阱格后退 3 格，安全岛允许异色飞机共存且免受撞击。离开安全岛后恢复普通碰撞规则；停机坪和归航道不触发特殊格。关闭的特殊格恢复为普通格。
- 幸运格由服务器等概率抽取前进 1、2、3 格或后退 1、2、3 格。前进可进入本色归航道，最多到终点；后退不低于本方外环起点，不回机场。额外移动遇敌墙停在墙前，不破墙或反弹；前进落点撞击计入踩次数，后退落点撞击不计。
- 冰冻格为一次性随机格：本局所有玩家累计第 20、40、60……次有效掷骰时，由服务器在没有飞机的普通公共外环格生成一个，替换尚未消耗的旧格；每次六点连掷及超时自动掷骰均计入，非法请求和跳过掷骰阶段不计。只有首架直接或正常跳跃／飞行落入的飞机被冻结，然后该格消失；加速、陷阱、幸运或偷袭额外移动落入时不连锁触发。被冻结的飞机必须掷出 6 点并选择它移动才能解冻，同色其他飞机不受影响；被撞回机场或完成比赛会清除冻结。冰格位置、掷骰计数和冻结状态均随房间快照保留。
- 趣味模式直接落到特殊格时，特殊效果替代该次同色跳跃或飞行；普通格奖励移动后落到特殊格，也结算一次特殊效果。加速、后退或幸运的最终落点正常判撞，但不再触发同色奖励或特殊格连锁。
- 加速的额外两步遇敌墙只停在墙前，不反弹、不自爆；陷阱后退遇敌墙也停在墙前。趣味模式安全岛上的叠子不算墙。
- 趣味模式撞飞敌机时显示撞飞台词和约一秒的短动画，不阻挡掷骰或走棋；系统设置减少动态效果时仅显示静态台词。
- 经典模式的自爆破墙、堵路反弹显示同步台词和约一秒的短动画；趣味模式通过“台词与动画”开关控制演出。刷新、重连、角色接管不会重播旧事件。趣味模式在候机与对局中均可打开“玩法简介”，查看规则和本局启用的玩法。
- 对局中可展开“关键事件”，查看最近 50 条开局、撞飞、破墙、反弹、特殊格、解冻、结盟／背叛、道具、抵达／排名、挂机／恢复、跳过阶段和超时托管记录。一次移动的多个效果合并为一条描述，普通掷骰和普通移动不挤占记录；全部由服务器生成并随房间快照同步，刷新、断线重连和角色接管后保留。宽屏时事件在棋盘左侧、盟友与道具在右侧；空间不足时优先将事件移到棋盘下方，窄屏两者都下置且事件在前。面板可折叠，浏览旧事件时保持阅读位置。
- 启用结盟后，玩家可发送邀请，对方接受才生效，每人最多一名盟友。待接受的邀请可撤回或拒绝。盟友之间不能互撞，彼此的墙也不阻挡；每名玩家每局可背叛一次，立即解除联盟，获得一次偷袭奖励：下一次自己走棋主动撞飞敌机后额外前进 2 格，遇敌墙停在墙前，额外落点不触发奖励连锁。道具、被动后退撞击和自爆破墙不消耗偷袭奖励；直接落入冰冻格时冻结优先，偷袭奖励保留到后续主动撞击。已完成玩家退出联盟。
- 启用道具后，每位玩家开局获得定身咒、地雷、导弹各一张，用后消耗；未开启机长时不再额外抽牌。每个轮次在掷骰前最多使用一张，掷出六点再次掷骰仍属于同一轮次。定身咒冻结一架公共外环上的敌机，须掷出六点并选择它移动才能解冻；地雷放在己方飞机当前的普通外环格，公开标记，首架敌机落入后回机场并消耗地雷；导弹从己方一架公共外环飞机发射，击落前方 1～6 格内指定的一架敌机。盟友不能成为攻击目标，安全岛免受导弹与地雷；飞机回机场后清除冻结。完成玩家的地雷清除。手牌只向本人公开，其他玩家和观战者只能看到数量，换设备接管会继承手牌。
- 落点先判定地雷和撞击，再判定同色跳跃／飞行；踩中敌方地雷返航后不再跳飞，飞越途中未落入的地雷不会触发，己方和盟友地雷不触发。导弹选项只列出当前有合法攻击目标的己方飞机，再列出该机前方符合条件的敌机；无匹配时显示“暂无符合条件的飞机／敌机”。
- 开启“台词与动画”时，导弹显示从发射飞机飞向目标的尾迹，随后显示命中闪光与返航动画，约一秒内清理；减少动态效果时仅显示静态台词，刷新、重连或接管不重播。
- 玩家卡片显示本局参与颜色的“踩次数”，自己的颜色在前，其余按座位顺序。对手颜色表示自己主动撞回该颜色飞机的数量；自己的颜色表示自爆破墙回机场的次数。普通主动撞飞及加速、幸运前进、偷袭落点撞飞，每架敌机加一次；破墙按墙上每架敌机分别累加，自己的颜色只加一次。导弹击落和地雷击落计入道具使用者的对应敌机颜色；被撞者不增加自己颜色次数。定身、被撞、陷阱或幸运后退、堵路反弹、安全岛共存、己方或盟友叠子均不增加次数。所有计数由服务器判定，刷新或换设备接管后保留。
- 主环走完后进入本色归航道，终点超点反弹。四架飞机全部到达的玩家依次记录第 1、2、3 名，继续由未完成玩家比赛；只剩一人未完成时自动排最后一名并结束。两人局仍在首人全部到达时结束。完成者退出回合轮转，即使用六点完成也不再额外掷骰；结算榜显示全部玩家名次和统计。
- 每次掷骰或走棋操作限时九十秒，超时由服务器自动掷骰或移动一架合法飞机；结盟和道具操作不会延长倒计时。
- 游戏进行中，尚未完成的玩家可点击“挂机”或“取消挂机”；房主也可在“房间管理”设置任意未完成座位的挂机状态。挂机标记显示在玩家卡片上，刷新、断线重连和角色接管后保留；取消挂机后可继续操作。挂机时不能手动掷骰、走棋、使用道具或进行联盟操作，开关挂机不延长阶段倒计时。
- 轮到挂机玩家时，其他仍在比赛且未挂机的入座玩家可选择跳过其当前掷骰／走棋阶段：未掷骰时不产生骰子，已掷骰时放弃本次待走棋，直接轮到下一位未完成玩家；连续六点计数清零，此前已经移动的飞机、统计和道具效果保留。观战者、已完成玩家及挂机者本人不能跳过；同一阶段的并发跳过仅生效一次。挂机玩家仍正常参加轮转，其他人不跳过时，原有九十秒超时自动走棋继续生效。完成比赛、返回候机或开始新局会清除挂机标记。

## 机长技能（可选）

房主可在趣味模式开启“机长技能”，同时开启结盟和道具；经典模式不启用技能。入座玩家在候机时选择一位机长，可以选择相同机长，所有人选完才能开局。开局后锁定选择，主动技能每人每局可用次数：闪现者 3 次、护盾者 2 次、赌徒 3 次，背叛者和复仇者各 1 次。机长、护盾、待用效果和已用次数绑定座位，刷新、断线重连或换设备接管后保留。

| 机长 | 主动技能 | 被动技能 |
| --- | --- | --- |
| ⚡ 闪现者 | 掷骰后、选机前启动，本次移动结束后额外前进最多 3 格 | 掷出 6 点时实际移动步数 +1，每次连续掷 6 均生效 |
| 🛡️ 护盾者 | 掷骰前给己方一架外环或归航道飞机加一层护盾，免疫一次敌方撞击、导弹或地雷 | 实际回机场时保留 1 步，下次从停机坪进入外环额外前进 1 格，不累积 |
| 🗡️ 背叛者 | 掷骰前交换己机与盟友各一架外环飞机的位置 | 每次攻击操作实际撞飞敌机后，随机从被撞方偷一张道具 |
| 🔥 复仇者 | 掷骰前锁定一架曾撞回己机的敌机，己机下一次可追击的移动直接追到该敌机当前外环格 | 被敌方撞击或导弹、地雷击落后，下一个真正轮次的首次骰子移动步数 +2，不累积 |
| 🎲 赌徒 | 掷骰后、选机前强制重掷一次，新点数必须接受 | 每次实际掷出 1 点随机获得一张道具 |

- 闪现不用于飞机从机场出门；可以用于停机坪进入外环。额外移动遇墙停在墙前，不连锁触发颜色或特殊格奖励；本次被送回机场或落入冰冻格时不追加。已启用的闪现若被挂机跳过，次数不退还。
- 闪现者被动将骰面 6 的实际步数改为 7，与主动闪现的额外最多 3 格可以叠加。出机场仍只到本色停机坪，从停机坪进入外环及正常走棋使用 7 步；冻结解锁与六点连掷仍按骰面 6 判定，墙距离与终点反弹使用实际步数。其他机长、未启用机长及经典模式不获得此加成；所有玩家掷 6 可继续、不限制连续次数的基础规则保持不变。
- 护盾跟随飞机，吸收攻击时消耗，不增加任何撞飞统计或偷牌。护盾不能免除己方主动自爆破墙；墙内敌机的护盾仍可吸收一次攻击。飞机返回机场或到达终点时清除护盾，安全岛上未发生攻击时不消耗。
- 交换仅支持两架飞机的落点都能映射到各自公共外环的位置，不跨私人停机坪或归航道；不触发撞击、地雷或落点奖励。冻结和护盾随原飞机保留，交换不解除冻结。
- 复仇追击需要己机已在外环，目标仍是可到达的外环敌机；直接追击可跨过沿途墙，但落点仍受墙、地雷、安全岛和护盾规则约束，不触发颜色或特殊格奖励。目标返航、到达终点、成为盟友或暂时无法映射时保留锁定。实际被撞的来源飞机由服务端记录，不能由客户端伪造。
- 骰面始终为 1～6；闪现者被动、复仇和保留进度只改变实际步数。出机场、冰冻解锁、六点连掷依据骰面；前进、墙距离和终点反弹依据实际步数。复仇 +2 在下一个新轮次的首骰消耗，掷 6 连掷不再重复加成。
- 手牌上限为 3 张；满手时不抽牌、不偷牌，被撞方保留原牌。偷牌每次攻击操作至多一张；普通撞飞、破墙、导弹和地雷的实际击落可触发，护盾吸收和安全岛共存不触发。事件仅公开抽牌／偷牌事实，不公开卡名，具体手牌仍只向本人发送。
- 赌徒首次掷骰没有合法飞机时仍可重掷，也可接受结果并换人。重掷的两个实际投掷都计入全桌冰冻格生成的 20 次计数，掷 1 已获得的牌不回退；连续六点和再次掷骰资格只按最终接受骰面计算。超时自动接受或走棋，不代替玩家使用主动技能。
- 主动技能不能由观战、挂机或已完成玩家使用；侧操作不延长倒计时，已消耗的一次使用机会不会随连掷、跳过、刷新或接管重置。新局重置技能状态；完成比赛清除待用效果与护盾。技能和抽牌事件沿用房间快照、关键事件和短动画机制，不增加独立同步接口。

## 联机和部署

服务器通过 HTTP 接收动作，通过 SSE 向玩家同步房间状态。骰子、回合、移动和胜负均由服务器判定。刷新页面会用本标签页保存的身份重连；房间内支持换位和离座观战，游戏中锁定座位。

部署脚本与专属 systemd 服务在 `deploy/`。程序放到 `/opt/sky-ludo/current` 后以 root 执行 `bash deploy/install.sh`，使用独立的 `sky-ludo` 用户运行。默认端口 8080，不修改现有服务。私钥不属于项目，也不应上传到服务器应用目录。

房间状态保存在内存中；服务重启会结束当前房间。需要长期保存战绩或使用域名 HTTPS 时，可在此基础上增加持久化与反向代理。
